🚀 БЫСТРЫЙ СТАРТ

1. УСТАНОВКА (2 минуты)
   → Откройте chrome://extensions/
   → Включите "Режим разработчика"
   → "Загрузить распакованное" → выберите /workspace

2. НАСТРОЙКА (2 минуты)
   → Получите API ключ на lzt.market
   → Откройте расширение → ⚙️ Настройки
   → Вставьте API ключ → Сохранить

3. ИСПОЛЬЗОВАНИЕ (1 минута)
   → Откройте lzt.market
   → Нажмите кнопку 🛠️ в правом нижнем углу
   → Выберите любую функцию!
