📦 БЫСТРАЯ УСТАНОВКА (Chrome/Edge/Brave/Opera):

  1️⃣  Откройте chrome://extensions/
      (или edge://extensions/ для Edge)
  
  2️⃣  Включите "Режим разработчика" в правом верхнем углу
  
  3️⃣  Нажмите "Загрузить распакованное расширение"
  
  4️⃣  Выберите эту папку (/workspace)
  
  5️⃣  Готово! ✅

🚀 КАК ИСПОЛЬЗОВАТЬ:

  → Откройте любую главу на https://ranobelib.me/
  → Нажмите кнопку 📝 в правом нижнем углу
  → Или нажмите Ctrl+Shift+A
  → Расширение начнет автоматически читать главы!

⚙️ НАСТРОЙКИ:

  Нажмите на иконку расширения в панели браузера,
  чтобы настроить:
  
  • Скорость прокрутки (10-200мс)
  • Шаг прокрутки (50-300px)  
  • Задержка между главами (0.5-5с)

💡 РЕКОМЕНДУЕМЫЕ НАСТРОЙКИ:

  Для БЫСТРОГО чтения:
    Скорость: 30мс
    Шаг: 150px
    Задержка: 1.5с
  
  Для НАДЕЖНОГО засчитывания:
    Скорость: 50мс
    Шаг: 100px
    Задержка: 2с

⌨️ ГОРЯЧИЕ КЛАВИШИ:

  Ctrl + Shift + A  →  Включить/выключить авто-чтение

🎯 ВАЖНО:

  ✓ Расширение засчитывает главы как прочитанные
  ✓ Автоматически переходит к следующей главе
  ✓ Останавливается на последней доступной главе
  ✓ Можно остановить в любой момент
