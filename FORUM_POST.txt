[size=16][color=red][b]📋 ОПИСАНИЕ:[/b][/color][/size]

Arizona Admin Helper - это современный и удобный помощник для администраторов сервера Arizona RP, специально разработанный для использования на мобильных устройствах Android с MonetLoader. 

Скрипт предоставляет полный набор инструментов для эффективного управления сервером прямо с вашего телефона! Красивый интерфейс, интуитивно понятное управление, настраиваемые темы - всё для комфортной работы администратора.

[color=lime]✅ Более 50+ админских функций в одном скрипте![/color]
[color=lime]✅ Удобный сенсорный интерфейс с большими кнопками![/color]
[color=lime]✅ 6 готовых цветовых тем + кастомизация![/color]
[color=lime]✅ Работает на телефонах Android![/color]

[size=14][color=cyan][b]👤 УПРАВЛЕНИЕ ИГРОКАМИ:[/b][/color][/size]

[color=orange]🚫 KICK (Кик игрока)[/color]
├─ Удаление игрока с сервера
├─ Требуется: ID игрока, Причина
└─ Команда: /kick [id] [причина]

[color=orange]🔨 BAN (Бан игрока)[/color]
├─ Блокировка доступа игрока к серверу
├─ Требуется: ID игрока, Количество дней, Причина
└─ Команда: /ban [id] [дни] [причина]

[color=orange]🔇 MUTE (Мут игрока)[/color]
├─ Блокировка чата игроку
├─ Требуется: ID игрока, Время в минутах, Причина
└─ Команда: /mute [id] [минуты] [причина]

[color=orange]⛓️ JAIL (Тюрьма)[/color]
├─ Посадка игрока в тюрьму
├─ Требуется: ID игрока, Время в минутах, Причина
└─ Команда: /jail [id] [минуты] [причина]

[color=orange]⚠️ WARN (Предупреждение)[/color]
├─ Выдача предупреждения игроку
├─ Требуется: ID игрока, Причина
└─ Команда: /warn [id] [причина]

[color=orange]❄️ FREEZE (Заморозка)[/color]
├─ Заморозка игрока на месте
├─ Требуется: ID игрока
└─ Команда: /freeze [id]

[color=orange]🔥 UNFREEZE (Разморозка)[/color]
├─ Отмена заморозки игрока
├─ Требуется: ID игрока
└─ Команда: /unfreeze [id]

[color=orange]💊 HEAL (Лечение)[/color]
├─ Восстановление здоровья игрока до 100%
├─ Требуется: ID игрока
└─ Команда: /sethp [id] 100

[color=orange]👁️ SPECTATE (Наблюдение)[/color]
├─ Наблюдение за игроком от первого лица
├─ Требуется: ID игрока
└─ Команда: /spec [id]

[color=orange]🚫 STOP SPECTATE (Остановка наблюдения)[/color]
├─ Выход из режима наблюдения
├─ Требуется: Ничего
└─ Команда: /specoff

[size=16][color=red][b]🎮 ИСПОЛЬЗОВАНИЕ:[/b][/color][/size]

[color=cyan][b]КОМАНДЫ:[/b][/color]
• [b]/chelper[/b] - Открыть/закрыть админ хелпер

[color=cyan][b]УПРАВЛЕНИЕ:[/b][/color]
• Интерфейс разделён на 5 вкладок для удобной навигации
• Просто выберите нужную вкладку и функцию
• Заполните необходимые поля (ID, причина, время)
• Нажмите на соответствующую кнопку
• Команда автоматически отправится в чат

[color=cyan][b]ПРИМЕР ИСПОЛЬЗОВАНИЯ:[/b][/color]
1. Откройте хелпер командой /chelper
2. Перейдите на вкладку "👤 Игроки"
3. Введите ID нарушителя
4. Введите причину наказания
5. Нажмите нужную кнопку (KICK/BAN/MUTE и т.д.)
6. Готово!
