# 🎨 Удаление фона с фотографий

Полностью функциональное веб-приложение для автоматического удаления фона с фотографий.

## ✨ Возможности

- ✅ Автоматическое удаление фона с любых фотографий
- ✅ Обработка прямо в браузере (не требуется сервер)
- ✅ Полная конфиденциальность - изображения не отправляются на внешние серверы
- ✅ Поддержка Drag & Drop
- ✅ Сравнение оригинала и результата
- ✅ Скачивание обработанных изображений в формате PNG
- ✅ Современный и красивый интерфейс
- ✅ Адаптивный дизайн для мобильных устройств

## 🚀 Как использовать

### Вариант 1: Прямое открытие (рекомендуется)

1. Просто откройте файл `index.html` в любом современном браузере
2. Готово! Приложение работает полностью в браузере

### Вариант 2: С локальным сервером

Если у вас возникают проблемы с CORS при открытии напрямую:

```bash
# Установите зависимости (опционально)
npm install

# Запустите локальный сервер
npm start
```

Затем откройте браузер и перейдите по адресу `http://localhost:3000`

### Вариант 3: Python HTTP Server

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере

## 📖 Инструкция по работе

1. **Загрузите фото**
   - Нажмите на область загрузки или перетащите фото
   - Поддерживаются форматы: JPG, PNG, WEBP

2. **Дождитесь обработки**
   - Приложение автоматически обработает изображение
   - Это может занять несколько секунд в зависимости от размера фото

3. **Сравните результат**
   - Вы увидите оригинал и обработанное изображение рядом

4. **Скачайте результат**
   - Нажмите кнопку "Скачать результат"
   - Изображение сохранится в формате PNG с прозрачным фоном

## 🛠️ Технологии

- **HTML5** - структура страницы
- **CSS3** - современный дизайн с градиентами и анимациями
- **JavaScript (ES6+)** - логика приложения
- **@imgly/background-removal** - AI-библиотека для удаления фона
- **ONNX Runtime** - машинное обучение в браузере

## 🎯 Особенности

- **Без сервера**: Вся обработка происходит на вашем устройстве
- **Конфиденциально**: Ваши фото не загружаются на внешние серверы
- **Бесплатно**: Полностью бесплатное использование
- **Быстро**: Оптимизированная обработка с использованием WebAssembly
- **Качественно**: Использует современные AI-модели для точного удаления фона

## 💡 Советы

- Для лучшего результата используйте фотографии с четким контрастом между объектом и фоном
- Первая обработка может занять больше времени из-за загрузки AI-модели
- Рекомендуется использовать на устройствах с достаточным объемом памяти
- Для больших изображений обработка может занять до 30 секунд
