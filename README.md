## 📱 Описание

**Arizona Admin Helper** - это профессиональный помощник для администраторов сервера Arizona RP, специально оптимизированный для использования на мобильных устройствах Android с MonetLoader.

## 📥 Установка

### Требования:
1. **Android** устройство
2. **SAMP Mobile** (SA-MP для Android)
3. **MonetLoader** установленный и рабочий

### Шаги установки:

1. Скачайте файл `Arizona_Admin_Helper.lua`

2. Переместите файл в папку MonetLoader:
   ```
   /sdcard/Android/data/com.nvidia.sampgta/files/MonetLoader/
   ```
   или
   ```
   /storage/emulated/0/Android/data/com.nvidia.sampgta/files/MonetLoader/
   ```

3. Перезапустите игру или перезагрузите скрипты

4. Готово! Используйте команду `/chelper` для открытия меню

## 🎮 Использование

### Команды:
- `/chelper` - Открыть/закрыть админ хелпер

### Интерфейс:

Хелпер имеет **5 вкладок**:

1. **👤 Игроки** - Управление игроками
2. **🌍 ТП** - Телепортация
3. **🚗 Авто** - Транспорт
4. **🔫 Оружие** - Выдача оружия
5. **⚙️ Настройки** - Настройка темы и информация

### Как пользоваться:

#### Управление игроками:
1. Введите **ID игрока**
2. Введите **причину** (для kick/ban/warn/etc)
3. Введите **время** (для ban/mute/jail)
4. Нажмите нужную кнопку

#### Телепортация:
- Для ТП к игроку: введите ID и нажмите "К ИГРОКУ"
- Для ТП по координатам: введите X, Y, Z и нажмите "ТЕЛЕПОРТ"
- Для быстрой ТП: просто нажмите на нужную локацию

#### Транспорт:
- Введите ID транспорта и нажмите "SPAWN"
- Или выберите популярный транспорт из списка

#### Оружие:
- Просто нажмите на нужное оружие

#### Настройки:
- Выберите готовую тему или настройте свой цвет
- Нажмите "СОХРАНИТЬ НАСТРОЙКИ" для сохранения
