# 📝 RanobeLib Auto Reader

Браузерное расширение для автоматического чтения новелл и ранобэ на сайте [ranobelib.me](https://ranobelib.me/)

## 🌟 Возможности

- ✅ **Автоматическое чтение глав** - расширение само прокручивает главу и переходит к следующей
- ⚡ **Быстрая прокрутка** - настраиваемая скорость чтения
- 🎯 **Засчитывание прочтения** - сайт регистрирует главы как прочитанные
- ⌨️ **Горячие клавиши** - `Ctrl+Shift+A` для быстрого запуска
- 🎨 **Красивый интерфейс** - современная кнопка с анимацией
- ⚙️ **Гибкие настройки** - управление скоростью и задержками

## 📦 Установка

### Google Chrome / Microsoft Edge / Brave / Opera

1. **Скачайте расширение**
   - Скачайте все файлы из этой папки

2. **Откройте страницу расширений**
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Opera: `opera://extensions/`

3. **Включите режим разработчика**
   - В правом верхнем углу включите переключатель "Режим разработчика" (Developer mode)

4. **Загрузите расширение**
   - Нажмите кнопку "Загрузить распакованное расширение" (Load unpacked)
   - Выберите папку с файлами расширения

5. **Готово!**
   - Расширение установлено и готово к использованию

### Mozilla Firefox

1. **Скачайте расширение**
   - Скачайте все файлы из этой папки

2. **Откройте страницу отладки**
   - Введите `about:debugging` в адресную строку
   - Нажмите "This Firefox" (Этот Firefox)

3. **Загрузите временное дополнение**
   - Нажмите "Load Temporary Add-on" (Загрузить временное дополнение)
   - Выберите файл `manifest.json` из папки расширения

4. **Готово!**
   - Расширение установлено (будет активно до перезапуска браузера)

## 🚀 Как использовать

1. **Откройте главу** на сайте ranobelib.me
2. **Нажмите кнопку 📝** в правом нижнем углу страницы
   - Или используйте горячую клавишу `Ctrl+Shift+A`
3. **Расширение начнет автоматически**:
   - Прокручивать текст главы
   - Переходить к следующей главе
   - Продолжать пока не достигнет последней доступной главы

### Остановка чтения

- Нажмите кнопку еще раз (она изменится на ⏸️)
- Или используйте `Ctrl+Shift+A`

## ⚙️ Настройки

Нажмите на иконку расширения в панели браузера, чтобы открыть настройки:

- **Скорость прокрутки** (10-200мс) - как быстро прокручивается страница
  - Меньше значение = быстрее прокрутка
  - Рекомендуется: 50мс

- **Шаг прокрутки** (50-300px) - насколько прокручивается за раз
  - Больше значение = быстрее прокрутка
  - Рекомендуется: 100px

- **Задержка перед следующей главой** (0.5-5с) - пауза между главами
  - Дает сайту время зарегистрировать прочтение
  - Рекомендуется: 2с

### Рекомендуемые настройки для быстрого чтения

```
Скорость прокрутки: 30мс
Шаг прокрутки: 150px
Задержка между главами: 1.5с
```

### Рекомендуемые настройки для надежного засчитывания

```
Скорость прокрутки: 50мс
Шаг прокрутки: 100px
Задержка между главами: 2с
```

## 🔧 Технические детали

### Файлы расширения

- `manifest.json` - конфигурация расширения
- `content.js` - основная логика автоматического чтения
- `styles.css` - стили для кнопки
- `popup.html` - интерфейс настроек
- `popup.js` - логика настроек
- `icon16.png`, `icon48.png`, `icon128.png` - иконки расширения

### Как это работает

1. Расширение добавляет кнопку на страницы чтения глав
2. При нажатии начинается плавная прокрутка страницы
3. По достижении конца главы расширение:
   - Ждет настроенное время (для регистрации прочтения)
   - Ищет кнопку "Следующая глава"
   - Переходит к следующей главе
   - Повторяет процесс

## ❓ Частые вопросы

**Q: Засчитывает ли сайт главы как прочитанные?**
A: Да! Расширение делает паузу между главами, чтобы сайт успел зарегистрировать прочтение.

**Q: Можно ли сделать еще быстрее?**
A: Да, уменьшите скорость прокрутки до 10мс и увеличьте шаг до 300px. Но учтите, что при слишком быстрой прокрутке сайт может не засчитать главу.

**Q: Расширение не находит следующую главу**
A: Попробуйте обновить страницу. Если проблема сохраняется, сайт мог изменить структуру - свяжитесь с разработчиком.

**Q: Можно ли использовать на мобильном устройстве?**
A: Да, если ваш мобильный браузер поддерживает расширения (например, Firefox для Android).
