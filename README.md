# 🎨 Удаление фона с фотографий

Современный веб-сайт для автоматического удаления фона с изображений. Работает полностью в браузере без отправки данных на сервер!

## ✨ Возможности

- 🚀 **Быстрая обработка** - удаление фона за несколько секунд
- 🎯 **Высокое качество** - использует современную библиотеку AI для точного определения объектов
- 🔒 **Приватность** - все обработки происходят локально в браузере
- 💾 **Скачивание PNG** - результат с прозрачным фоном в формате PNG
- 📱 **Адаптивный дизайн** - работает на компьютерах, планшетах и телефонах
- 🎨 **Современный UI** - красивый и удобный интерфейс

## 🚀 Быстрый старт

### Вариант 1: Просто открыть файл (рекомендуется)

1. Откройте файл `index.html` в любом современном браузере
2. Загрузите изображение
3. Дождитесь обработки
4. Скачайте результат!

### Вариант 2: Локальный сервер

Если у вас возникают проблемы с CORS или библиотека не загружается, используйте локальный сервер:

#### С Python:
```bash
# Python 3
python -m http.server 8000

# Откройте в браузере: http://localhost:8000
```

#### С Node.js:
```bash
# Установите http-server глобально
npm install -g http-server

# Запустите сервер
http-server -p 8000

# Откройте в браузере: http://localhost:8000
```

#### С PHP:
```bash
php -S localhost:8000

# Откройте в браузере: http://localhost:8000
```

## 📋 Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Активное интернет-соединение для загрузки библиотеки AI (при первом запуске)

## 🎯 Как использовать

1. **Загрузить изображение**
   - Нажмите "Выберите файл" или перетащите изображение в зону загрузки
   - Поддерживаются форматы: JPG, PNG, WebP

2. **Обработка**
   - Дождитесь автоматической обработки (обычно 5-15 секунд)
   - Прогресс отображается на экране

3. **Результат**
   - Сравните оригинал и результат
   - Нажмите "Скачать PNG" для сохранения
   - Или загрузите новое изображение

## 🐛 Решение проблем

### Библиотека не загружается
- Проверьте интернет-соединение
- Используйте локальный сервер (см. инструкции выше)
- Проверьте консоль браузера на наличие ошибок

### Медленная обработка
- Первая обработка может быть медленной (загрузка модели AI)
- Последующие обработки будут быстрее
- Для больших изображений требуется больше времени

### Браузер не поддерживается
- Используйте последнюю версию Chrome, Firefox или Edge
- Safari должен быть версии 14+
