# 🛠️ LZT Market Toolkit

Комплексное расширение для браузера для работы с [lzt.market](https://lzt.market/) - автоматизация, аналитика и инструменты для покупателей и продавцов.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🌟 Основные возможности

### 👨‍💼 Для продавцов

#### 💰 Финансовая аналитика
- **Автоматический подсчёт прибыли и убытков** - детальная статистика всех транзакций
- **Расчёт чистой прибыли** с учётом комиссий и расходов
- **Анализ рентабельности** - понимание эффективности вашего бизнеса
- **История продаж** с графиками и трендами

#### 📊 Управление товарами
- **Массовое редактирование** - изменение цен и описаний для множества товаров
- **Экспорт товаров** в JSON/CSV формате
- **Оптимизация цен** на основе анализа рынка
- **Автоматическое пополнение** товаров (при включении)

#### 🎯 Конкурентный анализ
- **Анализ конкурентов** по категориям
- **Отслеживание средних цен** на рынке
- **Выявление топ-продавцов** и их стратегий
- **Рекомендации по ценообразованию**

#### ⚡ Автоматизация
- **Авто-ответы** на частые вопросы
- **Автообновление цен** по рынку
- **Умные уведомления** о важных событиях

### 🛒 Для покупателей

#### 🔍 Анализ продавцов
- **Детальная проверка продавца** перед покупкой
- **Статистика убытков и прибыли** продавца
- **Рейтинг надёжности** на основе отзывов
- **История активности** и время ответа

#### 📥 Скачивание товаров
- **Быстрое скачивание** информации о товаре
- **Автоматическое форматирование** контента
- **Сохранение в удобном формате** (.txt)

#### 💵 Отслеживание цен
- **Мониторинг цен** на интересующие товары
- **Уведомления об изменениях** стоимости
- **История изменения цен**

#### 📊 Статистика покупок
- **Общая сумма** всех покупок
- **Количество транзакций**
- **Средний чек**
- **Аналитика трат**

## 🚀 Установка

### Вариант 1: Установка из исходников (Рекомендуется для разработки)

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/yourusername/lzt-market-toolkit.git
cd lzt-market-toolkit
```

2. **Откройте Chrome/Edge**
   - Перейдите в `chrome://extensions/` или `edge://extensions/`
   - Включите "Режим разработчика" в правом верхнем углу

3. **Загрузите расширение**
   - Нажмите "Загрузить распакованное расширение"
   - Выберите папку с расширением
   - Готово! 🎉

### Вариант 2: Firefox

1. **Откройте Firefox**
   - Перейдите в `about:debugging#/runtime/this-firefox`

2. **Загрузите временное дополнение**
   - Нажмите "Загрузить временное дополнение"
   - Выберите файл `manifest.json`
   - Готово! 🎉

## 📖 Использование

### Первоначальная настройка

1. **Откройте расширение** (нажмите на иконку в панели браузера)

2. **Перейдите в настройки** (вкладка ⚙️ Настройки)

3. **Добавьте API ключ**
   - Получите API ключ на [lzt.market](https://lzt.market/account/api)
   - Вставьте ключ в поле "API ключ LZT Market"
   - Нажмите "Сохранить"

### Для продавцов

#### 📊 Просмотр финансовой статистики

1. Откройте расширение
2. Перейдите на вкладку **💼 Продавец**
3. Нажмите **"Рассчитать"** в разделе "Финансовая статистика"
4. Изучите детальную информацию о прибылях и убытках

#### 🎯 Анализ конкурентов

1. В разделе "Аналитика конкурентов"
2. Введите категорию товара
3. Нажмите **"Анализировать"**
4. Получите данные о конкурентах и средних ценах

#### 💲 Оптимизация цен

1. Нажмите **"Оптимизация цен"**
2. Система проанализирует рынок
3. Получите рекомендации по ценообразованию

### Для покупателей

#### 🔍 Анализ продавца

**Способ 1: Через расширение**
1. Откройте расширение
2. Вкладка **🛒 Покупатель**
3. Введите имя продавца
4. Нажмите **"Анализировать"**

**Способ 2: На странице lzt.market**
1. Откройте профиль продавца
2. Нажмите на плавающую кнопку расширения (🛠️)
3. Выберите **"Анализ продавца"**

#### 📥 Скачивание товара

1. Откройте страницу товара на lzt.market
2. Нажмите на плавающую кнопку расширения (🛠️)
3. Выберите **"Скачать товар"**
4. Товар сохранится в формате .txt

#### 🔔 Отслеживание цен

1. Откройте страницу товара
2. Нажмите на плавающую кнопку расширения
3. Выберите **"Отслеживать цену"**
4. Получайте уведомления при изменении стоимости

### 🧮 Калькулятор прибыли

Доступен на любой странице lzt.market:

1. Нажмите на плавающую кнопку расширения (🛠️)
2. Выберите **"Калькулятор прибыли"**
3. Введите:
   - Цену покупки
   - Цену продажи
   - Комиссию (%)
4. Получите расчёт прибыли и рентабельности

## ⚙️ Настройки и конфигурация

### API ключ

API ключ необходим для полного функционала:

1. Войдите на [lzt.market](https://lzt.market/)
2. Перейдите в настройки аккаунта
3. Найдите раздел API
4. Скопируйте ключ
5. Вставьте в расширение

### Уведомления

Можно настроить уведомления для:
- ✅ Покупок
- ✅ Сообщений
- ✅ Изменения цен

### Автоматизация

Доступные опции:
- **Автоматическое пополнение товаров** - автоматическая загрузка новых товаров
- **Автообновление цен** - динамическое изменение цен по рынку
- **Автоответы** - автоматические ответы на частые вопросы

## 📊 Экспорт данных

Все данные можно экспортировать:

1. Перейдите в **⚙️ Настройки**
2. Раздел "Данные"
3. Нажмите **"Экспорт данных"**
4. Сохраните JSON файл

Данные включают:
- Историю анализа продавцов
- Отслеживаемые товары
- Статистику покупок/продаж
- Все настройки

## 🔒 Безопасность и конфиденциальность

- ✅ **Локальное хранение** - все данные хранятся локально в браузере
- ✅ **Без отправки данных** - никакие данные не отправляются на сторонние серверы
- ✅ **Безопасный API ключ** - ключ хранится только локально
- ✅ **Открытый исходный код** - код доступен для проверки
