# 🎮 Roblox Auto Register - Расширение для автоматической регистрации

Расширение для Chrome/Edge, которое автоматически заполняет форму регистрации на Roblox.com с сохранением всех данных в логах.

## 📋 Возможности

- ✅ **Автоматическое заполнение всех полей:**
  - Случайная дата рождения (возраст 13-25 лет)
  - Случайный username
  - Случайный пароль (минимум 12 символов)
  - Случайный выбор пола

- 💾 **Система логирования:**
  - Автоматическое сохранение всех зарегистрированных аккаунтов
  - Просмотр истории регистраций
  - Копирование данных отдельного аккаунта
  - Экспорт всех данных в TXT файл
  - Копирование всех логов в буфер обмена

- 🎨 **Современный интерфейс:**
  - Красивый градиентный дизайн
  - Удобное управление
  - Счетчик зарегистрированных аккаунтов
  - Статус выполнения операций

## 🚀 Установка

### Способ 1: Установка в Chrome/Edge

1. Скачайте все файлы расширения
2. Откройте браузер Chrome или Edge
3. Перейдите по адресу:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. Включите **"Режим разработчика"** (Developer mode) в правом верхнем углу
5. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked)
6. Выберите папку с файлами расширения
7. Расширение установлено! ✅

### Способ 2: Создание иконок (опционально)

Расширение требует иконки. Вы можете:
- Создать свои иконки 16x16, 48x48 и 128x128 пикселей
- Или временно закомментировать строки с иконками в `manifest.json`

## 📖 Использование

1. **Откройте страницу регистрации Roblox:**
   - Перейдите на https://www.roblox.com
   - Нажмите на кнопку "Sign Up" или откройте форму регистрации

2. **Запустите расширение:**
   - Кликните на иконку расширения в панели браузера
   - Нажмите кнопку **"▶ Начать регистрацию"**

3. **Просмотр логов:**
   - Все данные автоматически сохраняются в расширении
   - Вы можете скопировать данные любого аккаунта
   - Экспортировать все данные в TXT файл
   - Очистить логи при необходимости

## 🔧 Технические детали

### Генерация данных:

**Username:**
- Формат: [Префикс][Слово][Суффикс]
- Примеры: CoolGamerPro, EpicWarrior123, SuperHunterXD

**Password:**
- Длина: 12 символов
- Включает: буквы (a-z, A-Z), цифры (0-9), спецсимволы

**Дата рождения:**
- Случайный возраст от 13 до 25 лет
- Случайный месяц (1-12)
- Случайный день (1-28)

**Пол:**
- Случайный выбор: Male или Female

### Хранение данных:

- Используется Chrome Storage API
- Данные сохраняются локально в браузере
- Безопасное хранение без отправки на сервер

## ⚠️ Важные замечания

1. **Использование на свой риск:**
   - Это расширение создано в образовательных целях
   - Массовое создание аккаунтов может нарушать правила Roblox
   - Используйте ответственно

2. **Изменения на сайте Roblox:**
   - Roblox может изменить структуру формы регистрации
   - В этом случае может потребоваться обновление селекторов в `content.js`

3. **Сохранность данных:**
   - Регулярно экспортируйте логи в TXT файл
   - При удалении расширения все логи будут потеряны

## 🛠️ Решение проблем

**Расширение не работает:**
1. Проверьте, что вы на странице регистрации Roblox
2. Перезагрузите страницу Roblox
3. Переустановите расширение

**Форма не заполняется:**
1. Откройте консоль браузера (F12)
2. Проверьте наличие ошибок
3. Возможно, Roblox изменил селекторы - обновите `content.js`

**Логи не сохраняются:**
1. Проверьте разрешения расширения
2. Попробуйте очистить хранилище и начать заново
