# 🎨 Удаление фона с фотографий

Полнофункциональное веб-приложение для автоматического удаления фона с изображений. Работает полностью в браузере без загрузки изображений на сервер.

## ✨ Возможности

- 🚀 **Быстрая обработка** - удаление фона за несколько секунд
- 🔒 **Полная конфиденциальность** - все изображения обрабатываются локально в браузере
- 📱 **Адаптивный дизайн** - работает на всех устройствах
- 🎯 **Простой интерфейс** - перетащите изображение или выберите файл
- 💾 **Скачивание результата** - сохраните обработанное изображение в формате PNG
- 🎨 **Современный UI** - красивый градиентный дизайн

## 🚀 Как запустить

### Вариант 1: Простой Python сервер

```bash
# Запустите локальный сервер
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`

### Вариант 2: Использование любого другого веб-сервера

Вы можете использовать любой веб-сервер для статических файлов:

**Node.js (http-server):**
```bash
npx http-server -p 8000
```

**PHP:**
```bash
php -S localhost:8000
```

**Live Server в VS Code:**
- Установите расширение "Live Server"
- Щелкните правой кнопкой на `index.html`
- Выберите "Open with Live Server"

## 📖 Как использовать

1. Откройте сайт в браузере
2. Перетащите изображение в область загрузки или нажмите "Выберите файл"
3. Подождите несколько секунд, пока обрабатывается изображение
4. Сравните оригинал и результат
5. Нажмите "Скачать результат" для сохранения изображения без фона

## 🎯 Особенности

- **Без регистрации** - не требуется учетная запись
- **Без ограничений** - обрабатывайте сколько угодно изображений

- **Приватность** - ваши изображения не покидают ваш компьютер

## 🔧 Технические детали

Приложение использует современную библиотеку `@imgly/background-removal`, которая:
- Работает полностью на клиентской стороне
- Использует нейронные сети для точного определения объектов
- Не требует подключения к серверу для обработки
- Загружает ML-модели при первом использовании (кешируются браузером)

## 📝 Примечания

- При первом использовании потребуется загрузка ML-модели (~20-30 МБ)
- Модель кешируется браузером для последующих использований
- Время обработки зависит от размера изображения и мощности устройства
- Для лучшей производительности используйте современные браузеры (Chrome, Firefox, Edge)
