# 🔐 LookSMM Auto-Fill - Расширение для браузера

Автоматическое заполнение формы регистрации на сайте https://looksmm.ru/ с сохранением логов и паролей.

## 📋 Возможности

✅ **Автоматическое заполнение формы**
- Генерация случайного email
- Генерация случайного имени пользователя
- Генерация надежного пароля (16 символов)
- Автоматическое нажатие кнопки "Создать аккаунт"

✅ **Система логов**
- Сохранение всех созданных аккаунтов
- Отображение истории последних 10 аккаунтов
- Статистика создания аккаунтов

✅ **Экспорт данных**
- Сохранение всех аккаунтов в текстовый файл
- Удобный формат для чтения
- Полная информация о каждом аккаунте

✅ **Автоматический выход**
- Кнопка быстрого выхода из аккаунта
- Автоматический переход на страницу настроек
- Автоматический скролл и нажатие кнопки "Выход"

## 📦 Установка

### Шаг 1: Подготовка иконок

Перед установкой расширения необходимо создать иконки. Вы можете:

**Вариант А: Создать свои иконки**
- Создайте 3 PNG файла с размерами: 16x16, 48x48, 128x128 пикселей
- Назовите их: `icon16.png`, `icon48.png`, `icon128.png`
- Поместите в папку с расширением

**Вариант Б: Использовать онлайн-генератор**
1. Перейдите на https://favicon.io/emoji-favicons/locked/
2. Скачайте иконку с замком 🔐
3. Переименуйте файлы в нужные размеры

**Вариант В: Временно использовать любые PNG файлы**
- Просто создайте 3 одинаковых PNG файла любого размера
- Это позволит установить расширение (иконка будет работать, но может выглядеть не идеально)

### Шаг 2: Установка в Chrome/Edge

1. Откройте браузер Chrome или Edge
2. Перейдите по адресу: `chrome://extensions/` (или `edge://extensions/`)
3. Включите **"Режим разработчика"** в правом верхнем углу
4. Нажмите кнопку **"Загрузить распакованное расширение"**
5. Выберите папку с файлами расширения (`/workspace`)
6. Расширение установлено! ✅

### Шаг 3: Установка в Firefox

1. Откройте Firefox
2. Перейдите по адресу: `about:debugging#/runtime/this-firefox`
3. Нажмите **"Загрузить временное дополнение"**
4. Выберите файл `manifest.json` из папки расширения
5. Расширение установлено! ✅

## 🚀 Использование

### 1. Автозаполнение формы регистрации

1. Откройте страницу регистрации на https://looksmm.ru/
2. Нажмите на иконку расширения в панели браузера
3. Нажмите кнопку **"🚀 Начать автозаполнение"**
4. Расширение автоматически:
   - Заполнит все поля формы
   - Нажмет кнопку создания аккаунта
   - Сохранит данные в историю

### 2. Просмотр истории аккаунтов

1. Откройте popup расширения
2. В разделе **"История аккаунтов"** вы увидите:
   - Email
   - Имя пользователя
   - Пароль
   - Дату создания

### 3. Экспорт данных

1. Откройте popup расширения
2. Нажмите кнопку **"💾 Экспортировать в файл"**
3. Выберите место сохранения файла
4. Файл будет содержать все созданные аккаунты

### 4. Выход из аккаунта

1. Откройте popup расширения
2. Нажмите кнопку **"🚪 Выход из аккаунта"**
3. Расширение автоматически:
   - Откроет страницу https://looksmm.ru/profile/settings
   - Прокрутит страницу вниз
   - Нажмет кнопку "Выход"

## 🔧 Технические детали

### Генерация данных

**Email:**
- Случайная строка из 10 символов
- Домены: gmail.com, yahoo.com, outlook.com, mail.ru, yandex.ru

**Имя пользователя:**
- Комбинация случайного прилагательного + существительного + числа
- Пример: `CoolGamer1234`

**Пароль:**
- 16 символов
- Включает: строчные, заглавные буквы, цифры, спецсимволы
- Высокий уровень безопасности

### Хранение данных

Все данные хранятся локально в браузере с использованием `chrome.storage.local`:
- История аккаунтов
- Логи создания
- Временные метки

**Безопасность:** Данные не отправляются на внешние серверы.

## 🐛 Решение проблем

### Расширение не находит поля формы

**Решение:** Откройте консоль разработчика (F12) и проверьте логи. Расширение ищет поля по различным атрибутам. Возможно, нужно обновить селекторы в `content.js`.

### Не нажимается кнопка создания аккаунта

**Решение:** Проверьте текст кнопки на сайте. Добавьте его в массив `buttonTexts` в функции `clickCreateAccountButton()` файла `content.js`.

### Не работает выход из аккаунта

**Решение:** Убедитесь, что вы авторизованы на сайте. Проверьте текст кнопки выхода и добавьте его в массив `logoutTexts` в функции `performLogout()` файла `content.js`.

### Данные не сохраняются

**Решение:** Проверьте права расширения в настройках браузера. Расширению нужен доступ к `storage`.
