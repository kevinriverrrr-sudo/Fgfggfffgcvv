# XRocket - Временная почта (Temp Email)

![XRocket Logo](icons/icon128.svg)

**Автор:** @MarkusGarantor

## 📧 О расширении

XRocket - это красивое и удобное расширение для браузера, которое позволяет создавать временные email адреса мгновенно. Идеально для регистрации на сайтах, тестирования и защиты вашей основной почты от спама.

## ✨ Возможности

- 🎯 **Мгновенная генерация email** - создавайте случайные адреса формата `xxx@xrocket.com` одним кликом
- 📬 **Входящие письма** - получайте и читайте письма прямо в расширении
- 🔄 **Обновление почты** - меняйте email адрес в любой момент
- 📋 **Копирование** - быстро копируйте адрес в буфер обмена
- 🎨 **Красивый дизайн** - современный интерфейс с градиентами и анимациями
- 🚀 **Автоматические письма** - реалистичная имитация получения писем от популярных сервисов

## 🚀 Установка

### Chrome/Edge/Brave

1. Откройте `chrome://extensions/` в браузере
2. Включите "Режим разработчика" в правом верхнем углу
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку с расширением XRocket
5. Готово! Иконка XRocket появится в панели расширений

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`
2. Нажмите "Загрузить временное дополнение"
3. Выберите файл `manifest.json` из папки расширения
4. Готово! Иконка XRocket появится в панели расширений

## 📖 Как использовать

1. **Создать почту**: Нажмите на иконку расширения и кликните "Получить почту"
2. **Скопировать адрес**: Используйте кнопку копирования рядом с email адресом
3. **Просмотр писем**: Письма появятся автоматически во вкладке "Входящие"
4. **Читать письма**: Кликните на любое письмо, чтобы прочитать его полностью
5. **Обновить почту**: Используйте кнопку обновления для создания нового адреса

- Градиентный фон с анимированной сеткой

- Современные SVG иконки
- Адаптивный интерфейс

## 📝 Технические детали

- Manifest V3 (современный стандарт)
- Использует Chrome Storage API для сохранения данных
- Background Service Worker для генерации писем
- Реалистичные шаблоны писем от популярных сервисов

## 🔒 Приватность

⚠️ **Важно:** Это демонстрационное расширение с имитацией получения писем. Письма генерируются локально и не являются реальными. Для работы с настоящей временной почтой необходим backend сервер.
