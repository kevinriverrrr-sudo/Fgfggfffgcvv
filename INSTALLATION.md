# 📦 Инструкция по установке LZT Market Toolkit

Подробное руководство по установке расширения в различных браузерах.

## 🌐 Поддерживаемые браузеры

- ✅ Google Chrome (версия 88+)
- ✅ Microsoft Edge (версия 88+)
- ✅ Brave Browser
- ✅ Opera (версия 74+)
- ⚠️ Mozilla Firefox (с ограничениями)
- ❌ Safari (не поддерживается)

---

## 📥 Установка в Google Chrome / Microsoft Edge / Brave

### Шаг 1: Скачайте расширение

**Вариант A: Из репозитория GitHub**
```bash
git clone https://github.com/yourusername/lzt-market-toolkit.git
cd lzt-market-toolkit
```

**Вариант B: Скачать ZIP**
1. Перейдите на [страницу релизов](https://github.com/yourusername/lzt-market-toolkit/releases)
2. Скачайте последнюю версию (lzt-market-toolkit-v1.0.0.zip)
3. Распакуйте архив в удобную папку

### Шаг 2: Откройте страницу расширений

**Google Chrome:**
1. Откройте Chrome
2. В адресной строке введите: `chrome://extensions/`
3. Или: Меню (⋮) → Расширения → Управление расширениями

**Microsoft Edge:**
1. Откройте Edge
2. В адресной строке введите: `edge://extensions/`
3. Или: Меню (⋯) → Расширения → Управление расширениями

**Brave:**
1. Откройте Brave
2. В адресной строке введите: `brave://extensions/`
3. Или: Меню (☰) → Расширения

### Шаг 3: Включите режим разработчика

В правом верхнем углу включите переключатель **"Режим разработчика"** (Developer mode)

![Developer Mode](https://user-images.githubusercontent.com/placeholder-developer-mode.png)

### Шаг 4: Загрузите расширение

1. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked)
2. Выберите папку с расширением (где находится manifest.json)
3. Нажмите "Выбрать папку"

### Шаг 5: Подтвердите установку

Расширение появится в списке с названием **"LZT Market Toolkit"**

### Шаг 6: Закрепите расширение

1. Нажмите на иконку расширений в панели инструментов (🧩)
2. Найдите LZT Market Toolkit
3. Нажмите на значок "булавки" 📌

**Готово!** 🎉

## 🦊 Установка в Mozilla Firefox

### ⚠️ Важно
Firefox использует другую систему расширений. Для постоянной установки требуется подпись Mozilla.

### Временная установка (для тестирования)

#### Шаг 1: Скачайте расширение
Следуйте инструкциям из раздела Chrome (Шаг 1)

#### Шаг 2: Откройте страницу отладки
1. Откройте Firefox
2. В адресной строке введите: `about:debugging#/runtime/this-firefox`
3. Или: Меню (☰) → Дополнительные инструменты → Расширения для разработчиков

#### Шаг 3: Загрузите временное дополнение
1. Нажмите **"Загрузить временное дополнение"** (Load Temporary Add-on)
2. Перейдите в папку расширения
3. Выберите файл **manifest.json**
4. Нажмите "Открыть"

#### ⚠️ Ограничения
- Расширение будет удалено после закрытия Firefox
- Нужно загружать заново при каждом запуске

### Постоянная установка в Firefox

Для постоянной установки необходимо:
1. Зарегистрироваться на [addons.mozilla.org](https://addons.mozilla.org/developers/)
2. Отправить расширение на проверку
3. Получить подпись Mozilla
4. Опубликовать в каталоге дополнений

Или использовать Firefox Developer Edition / Nightly с отключенной проверкой подписей.

## ⚙️ Первоначальная настройка

После установки настройте расширение:

### 1. Откройте расширение
Нажмите на иконку 🛠️ в панели инструментов

### 2. Получите API ключ

1. Откройте [lzt.market](https://lzt.market/)
2. Войдите в свой аккаунт
3. Перейдите в **Настройки** → **Безопасность** → **API**
4. Создайте новый API ключ или скопируйте существующий

### 3. Добавьте API ключ в расширение

1. В расширении перейдите на вкладку **⚙️ Настройки**
2. Найдите раздел "API настройки"
3. Вставьте ваш API ключ в поле "API ключ LZT Market"
4. Нажмите кнопку **"Сохранить"**

### 4. Настройте уведомления (опционально)

В разделе "Уведомления" выберите типы событий:
- ✅ Уведомления о покупках
- ✅ Уведомления о сообщениях
- ☐ Уведомления об изменении цен

### 5. Готово!

Расширение готово к использованию 🎉

## 🔍 Проверка установки

### Тест 1: Проверьте иконку
- Иконка расширения должна быть видна в панели инструментов
- При клике должно открыться всплывающее окно

### Тест 2: Проверьте интеграцию
1. Откройте [lzt.market](https://lzt.market/)
2. В правом нижнем углу должна появиться плавающая кнопка 🛠️
3. При клике должно открыться меню быстрых действий

### Тест 3: Проверьте функционал
1. Откройте расширение
2. Попробуйте функцию анализа продавца
3. Результаты должны отобразиться в интерфейсе

## ❗ Устранение проблем

### Проблема: Расширение не загружается

**Решение:**
- Убедитесь, что режим разработчика включён
- Проверьте, что выбрана правильная папка с manifest.json
- Обновите браузер до последней версии

### Проблема: Ошибка при загрузке

**Решение:**
- Проверьте, что все файлы расширения на месте
- Убедитесь, что manifest.json не повреждён
- Проверьте консоль браузера (F12) на наличие ошибок

### Проблема: Иконка не отображается

**Решение:**
- Иконки используют SVG формат
- Попробуйте перезагрузить расширение
- Проверьте папку icons/ на наличие файлов

### Проблема: Плавающая кнопка не появляется на lzt.market

**Решение:**
- Обновите страницу lzt.market (F5)
- Проверьте, что расширение имеет доступ к lzt.market
- Откройте консоль (F12) → вкладка Console → ищите ошибки

### Проблема: API ключ не работает

**Решение:**
- Проверьте правильность API ключа
- Убедитесь, что ключ не истёк
- Проверьте права доступа ключа на lzt.market

### Проблема: В Firefox расширение пропало после перезапуска

**Решение:**
- Это ожидаемое поведение для временных дополнений
- Загрузите расширение заново через about:debugging
- Для постоянной установки требуется подпись Mozilla

## 🔄 Обновление расширения

### Автоматическое обновление (после публикации в магазине)
Расширение обновится автоматически через магазин браузера

### Ручное обновление (из исходников)

1. Скачайте новую версию
2. Удалите старую версию:
   - chrome://extensions/ → Найдите расширение → Удалить
3. Установите новую версию (следуйте инструкциям выше)

### Обновление без потери данных

Все ваши данные (настройки, статистика) хранятся локально и сохранятся при обновлении.

**Для безопасности:**
1. Экспортируйте данные перед обновлением:
   - Откройте расширение → ⚙️ Настройки → Экспорт данных
2. После обновления можете импортировать данные обратно

## 🗑️ Удаление расширения

### Chrome / Edge / Brave

1. Откройте страницу расширений
2. Найдите "LZT Market Toolkit"
3. Нажмите **"Удалить"**
4. Подтвердите удаление

### Firefox

1. Откройте about:addons
2. Найдите расширение
3. Нажмите **"Удалить"**

### ⚠️ Важно
При удалении все локальные данные будут стёрты!

Перед удалением:
- Экспортируйте данные (⚙️ Настройки → Экспорт данных)
