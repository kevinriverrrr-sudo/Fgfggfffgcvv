# История изменений

Все заметные изменения в проекте LZT Market Toolkit будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2025-11-04

### Добавлено

#### Для покупателей
- 🔍 Анализ продавцов с детальной статистикой
  - Рейтинг и количество продаж
  - Расчёт прибыли и убытков
  - Время ответа
  - Положительные и отрицательные отзывы
- 📥 Скачивание товаров с автоматическим форматированием
- 🔔 Отслеживание цен на товары
- 📊 Статистика покупок (общая сумма, количество, средний чек)

#### Для продавцов
- 💰 Финансовая аналитика
  - Автоматический расчёт прибыли и убытков
  - Чистая прибыль с учётом комиссий
  - Рентабельность бизнеса
- 📈 Статистика продаж
  - Всего продаж
  - Активные товары
  - Рейтинг продавца
- 📦 Управление товарами
  - Массовое редактирование
  - Экспорт товаров в JSON
  - Оптимизация цен
- 🎯 Аналитика конкурентов
  - Анализ конкурентов по категориям
  - Средние цены на рынке
  - Топ продавцы
  - Доля рынка
- ⚡ Автоматизация
  - Автоматическое пополнение товаров
  - Автообновление цен по рынку
  - Автоматические ответы

#### Общие функции
- 🎨 Современный тёмный интерфейс
- ⚙️ Гибкие настройки
  - Управление API ключом
  - Выбор темы оформления
  - Настройка уведомлений
- 📊 Экспорт/импорт данных
- 🛠️ Плавающая кнопка на страницах lzt.market
  - Быстрый анализ продавца
  - Скачивание товара
  - Отслеживание цены
  - Копирование информации
  - Калькулятор прибыли
- 🧮 Калькулятор прибыли
  - Расчёт с учётом комиссии
  - Вычисление рентабельности
- 🔐 Безопасность
  - Локальное хранение данных
  - Защищённое хранение API ключа
  - Без отправки данных на сторонние серверы

#### Техническое
- Manifest V3 для современных браузеров
- Поддержка Chrome, Edge, Brave
- Поддержка Firefox (с ограничениями)
- Content scripts для интеграции с lzt.market
- Background service worker для фоновой обработки
- Контекстное меню для быстрого доступа

### Известные проблемы
- Иконки используют SVG вместо PNG (требуется замена для production)
- Некоторые функции требуют валидный API ключ
- Firefox может требовать дополнительную настройку manifest

### Будущие улучшения
- Графики и визуализация данных
- Экспорт в Excel/CSV
- Светлая тема
- Интеграция с Telegram
- Горячие клавиши
- AI-рекомендации

## Легенда типов изменений

- **Добавлено** - новые функции
- **Изменено** - изменения в существующем функционале
- **Устарело** - функции, которые скоро будут удалены
- **Удалено** - удалённые функции
- **Исправлено** - исправления багов
- **Безопасность** - изменения в безопасности
