## 🚀 Как начать использовать

### Шаг 1: Установка
```bash
cd /workspace
# Откройте chrome://extensions/
# Включите "Режим разработчика"
# "Загрузить распакованное" → выберите /workspace
```

### Шаг 2: Настройка
1. Получите API ключ на lzt.market
2. Откройте расширение → ⚙️ Настройки
3. Вставьте API ключ → Сохранить

### Шаг 3: Использование
- Откройте lzt.market
- Увидите кнопку 🛠️ в правом нижнем углу
- Попробуйте любую функцию!

## 🔧 Технические детали

### Архитектура
```
Extension Popup (popup.html/js)
    ↓
Content Script (content.js) ← → lzt.market
    ↓
Background Worker (background.js)
    ↓
Chrome Storage API
```

### Технологии
- **Frontend:** Vanilla JavaScript (ES6+)
- **Styling:** Pure CSS3
- **Storage:** Chrome Storage API
- **API:** Chrome Extension API (Manifest V3)

### Производительность
- Быстрая загрузка (< 100ms)
- Минимальное потребление памяти
- Асинхронная обработка
- Оптимизированные запросы

### Совместимость
- ✅ Chrome 88+
- ✅ Edge 88+
- ✅ Brave
- ✅ Opera 74+
- ⚠️ Firefox (временная установка)

## ⚠️ Важные замечания

### Иконки
🔔 **Внимание:** Иконки используют SVG формат с копиями .png

**Рекомендация:** Для production замените на настоящие PNG:
- Создайте 16x16, 48x48, 128x128 PNG
- Используйте векторный редактор (Figma, Illustrator)
- Сохраните в папку icons/

### API ключ
🔐 API ключ требуется для:
- Получения данных с lzt.market
- Анализа продавцов
- Статистики продаж
- Некоторых автоматизаций

Без ключа работают:
- Калькулятор прибыли
- Скачивание товаров (с текущей страницы)
- Базовый анализ (ограниченный)
