# Mobile Shooter - Project Summary

## Обзор проекта

**Mobile Shooter** — полноценный офлайн-шутер от первого лица для Android, созданный на Unity с упором на производительность и оптимизацию для мобильных устройств.

## Архитектура

### Основные компоненты

1. **Core** - Центральные системы управления
   - `GameManager` - жизненный цикл игры
   - `AIManager` - управление всеми ботами
   - `SpawnManager` - спавн врагов и лута
   - `WorldManager` - окружение и интерактивные объекты

2. **Player** - Система игрока
   - `PlayerController` - движение, прыжки, присед
   - `InputHandler` - обработка тач-управления и гироскопа
   - `WeaponManager` - управление арсеналом

3. **AI** - Искусственный интеллект
   - `BotAI` - восприятие, решения, навигация
   - `BotCombat` - боевая система ботов
   - Поддержка NavMesh для патрулирования

4. **Weapons** - Система оружия
   - `Weapon` - базовый класс оружия
   - `WeaponData` - ScriptableObject конфигурации
   - Система отдачи, разброса, модификаций

5. **UI** - Интерфейс
   - `UIManager` - HUD, меню, результаты
   - `MobileInputManager` - виртуальные джойстики
   - Touch-friendly дизайн

6. **Audio** - Звуковая система
   - `AudioManager` - 3D звук с пулом источников
   - Динамические шаги по поверхности
   - Категории: музыка, SFX, UI

7. **Settings** - Настройки
   - `SettingsManager` - графика, управление, звук
   - Автоопределение по железу
   - Адаптивная оптимизация

8. **Data** - Данные и прогресс
   - `DataManager` - сохранение/загрузка профиля
   - Система уровней и опыта
   - Разблокировка контента

9. **Utils** - Утилиты
   - `TelemetryManager` - локальная аналитика
   - `PerformanceMonitor` - мониторинг FPS
   - `DebugManager` - инструменты отладки

## Ключевые особенности

### Производительность
- Object Pooling для аудио и эффектов
- Адаптивное разрешение при падении FPS
- Автоматическое снижение качества графики
- Пресеты для разных уровней железа

### Мобильная оптимизация
- Виртуальные джойстики с настраиваемой чувствительностью
- Поддержка гироскопа для прицеливания
- Вибрация для тактильной обратной связи
- Landscape ориентация для комфортной игры

### AI система
- Конус зрения и слух для обнаружения игрока
- FSM (Finite State Machine): Patrol → Combat → Retreat → Cover
- Использование укрытий и тактических позиций
- 3 типа ботов с разным поведением

### Режимы игры
- **Survival**: выживание с непрерывным спавном
- **Wave Defense**: волны с растущей сложностью
- **Time Attack**: убить максимум за 5 минут

## Технологический стек

- **Engine**: Unity 2020.3 LTS+
- **Language**: C# 7.3+
- **Scripting Backend**: IL2CPP
- **Target Platform**: Android 5.0+ (API 21+)
- **Architecture**: ARM64 (Google Play), ARMv7 (legacy)
- **Build System**: Gradle

## Паттерны проектирования

1. **Singleton** - для менеджеров (GameManager, AudioManager, etc.)
2. **Object Pooling** - для часто создаваемых объектов
3. **State Machine** - для AI ботов
4. **Observer** - события для связи систем
5. **ScriptableObject** - для конфигурации контента

## Метрики производительности

### Целевые показатели
- **FPS**: 60 на средних устройствах, 30 на бюджетных
- **Память**: < 500 MB RAM usage
- **Батарея**: умеренное потребление
- **Размер APK**: 150-200 MB

### Оптимизации
- Static batching для статических объектов
- Occlusion culling для больших карт
- LOD (Level of Detail) для моделей
- Компрессия текстур (ASTC)
- Компрессия аудио (Vorbis)

## Безопасность

- **Offline-only**: нет сетевых запросов
- **No cheats**: базовая защита от читов
- **Keystore**: безопасная подпись APK
- **Обфускация**: ProGuard/R8 для релиза

## Расширяемость

### Добавление нового оружия
1. Создать WeaponData ScriptableObject
2. Настроить параметры
3. Создать префаб модели
4. Добавить в систему разблокировки

### Добавление новой карты
1. Создать сцену
2. Запечь NavMesh
3. Расставить спавн-точки и укрытия
4. Добавить в Build Settings

### Добавление нового типа бота
1. Расширить enum BotType
2. Настроить параметры в ConfigureByType()
3. Создать префаб
4. Добавить логику в SelectBotType()

## Известные ограничения

- NavMesh требует статическую геометрию
- Максимум 20 активных ботов одновременно
- Графика оптимизирована для mobile (не photorealistic)
- Офлайн-only (нет мультиплеера по сети)
