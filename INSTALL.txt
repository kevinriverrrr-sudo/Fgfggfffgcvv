📌 ШАГ 1: СОЗДАНИЕ ИКОНОК (ОБЯЗАТЕЛЬНО!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Перед установкой расширения нужно создать файлы иконок.

ВАРИАНТ А - Быстрый способ (любые PNG):
  1. Найдите любую PNG картинку (можно скачать из интернета)
  2. Скопируйте её 3 раза и назовите:
     - icon16.png
     - icon48.png  
     - icon128.png
  3. Поместите файлы в папку с расширением

ВАРИАНТ Б - С помощью онлайн-сервиса:
  1. Откройте: https://favicon.io/emoji-favicons/locked/
  2. Скачайте ZIP архив
  3. Извлеките PNG файлы нужных размеров
  4. Переименуйте в: icon16.png, icon48.png, icon128.png

ВАРИАНТ В - Если установлен ImageMagick:
  1. Запустите: bash create_icons.sh
  2. Иконки создадутся автоматически


📌 ШАГ 2: УСТАНОВКА В CHROME/EDGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Откройте Chrome или Edge
  2. Перейдите: chrome://extensions/
  3. Включите "Режим разработчика" (справа вверху)
  4. Нажмите "Загрузить распакованное расширение"
  5. Выберите эту папку (/workspace)
  6. Готово! ✅


📌 ШАГ 3: УСТАНОВКА В FIREFOX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Откройте Firefox
  2. Перейдите: about:debugging#/runtime/this-firefox
  3. Нажмите "Загрузить временное дополнение"
  4. Выберите файл manifest.json
  5. Готово! ✅


📌 ШАГ 4: ИСПОЛЬЗОВАНИЕ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 АВТОЗАПОЛНЕНИЕ:
  1. Откройте https://looksmm.ru/
  2. Нажмите на иконку расширения
  3. Нажмите "Начать автозаполнение"
  4. Форма заполнится автоматически!

🚪 ВЫХОД ИЗ АККАУНТА:
  1. Откройте расширение
  2. Нажмите "Выход из аккаунта"
  3. Выход выполнится автоматически!

💾 ЭКСПОРТ ДАННЫХ:
  1. Откройте расширение
  2. Нажмите "Экспортировать в файл"
  3. Сохраните файл с паролями
